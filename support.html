ChapterRoll Support

ChapterRoll is a local-first iPhone app for running chapter attendance in roll-number order.

Import a roster

  1. Open the Roster tab.
  2. Choose Import and select a CSV or text file from Files.
  3. Return to ChapterRoll and tap Start Roll Call.

ChapterRoll accepts a basic Name and Badge Number list or a nationals-style export containing First Name, Last Name, and Roll Number columns.

Correct an attendance mistake

During first roll, move backward or forward to revisit a member and select the correct status. During second roll, select a member from the list and update the copied status.

Export attendance

Open the completed session and choose Export CSV. The export includes name, badge number, first-roll status, and second-roll status.

Delete local data

Open Settings and choose Delete All Local Data. This removes the roster, attendance history, and any active roll from the device.

Contact support

Email brooks.modesitt@gmail.com with the iPhone model, iOS version, and a short description of what happened. Do not send real member information.
